Dynamic Programming

Edit Distance

Minimum insertions, deletions, and substitutions that turn one string into another. Also called Levenshtein distance.

Problem

Given strings s1 and s2, return the fewest single-character edits that transform s1 into s2. An edit is an insert, a delete, or a replace.

Idea

edit[i][j] is the distance between the first i characters of s1 and the first j characters of s2. The last characters are either already equal, or one edit has to account for them.

  • If they match, copy the distance of the prefixes before them. No new edit.
  • If they differ, pay 1 and choose the cheapest of three predecessors: delete from s1 (edit[i - 1][j]), insert into s1 (edit[i][j - 1]), or replace (edit[i - 1][j - 1]).

This is a minimum, not a maximum. The LCS recurrence does not apply here.

Recurrence

If s1[i - 1] == s2[j - 1]: edit[i][j] = edit[i - 1][j - 1]

Otherwise: edit[i][j] = 1 + min(edit[i - 1][j], edit[i][j - 1], edit[i - 1][j - 1])

Base cases: edit[i][0] = i (delete everything) and edit[0][j] = j (insert everything).

Algorithm

  1. Fill the first row and first column with 0, 1, 2, ….
  2. For every other cell, apply the match or the three-way minimum.
  3. edit[n][m] is the distance.

Worked example

s1 = "cat", s2 = "cut". Replace a with u. Distance 1.

""cut
""0123
c1012
a2112
t3221

Cell (a, u) is a mismatch, so it costs 1 + min(1, 1, 0) = 1. Cell (t, t) matches, so it copies the diagonal 1.

Complexity

Time O(n · m). Space O(n · m), or O(min(n, m)) when only the distance is required.

Python

def edit_distance(s1, s2):
    n, m = len(s1), len(s2)
    prev = list(range(m + 1))
    for i in range(1, n + 1):
        cur = [i] + [0] * m
        for j in range(1, m + 1):
            if s1[i - 1] == s2[j - 1]:
                cur[j] = prev[j - 1]
            else:
                cur[j] = 1 + min(prev[j], cur[j - 1], prev[j - 1])
        prev = cur
    return prev[m]
