Dynamic Programming

Longest Common Subsequence

Longest sequence that appears in both strings, in the same order, not necessarily contiguous.

Problem

Given two strings, return the length of their longest common subsequence. Characters may be skipped, but the relative order of the ones that are kept must match in both strings.

Idea

Compare the strings from the left, one character at a time. lcs[i][j] is the LCS length of the first i characters of the first string and the first j characters of the second.

If the current characters match, they belong in some optimal subsequence, so take both and add 1 to the answer for the prefixes before them. If they differ, at least one of them is useless for the optimum, so try dropping each end and keep the better result.

Recurrence

If s1[i - 1] == s2[j - 1]: lcs[i][j] = 1 + lcs[i - 1][j - 1]

Otherwise: lcs[i][j] = max(lcs[i - 1][j], lcs[i][j - 1])

Base case: a prefix of length 0 has LCS length 0. Filling row by row uses only the previous row, so the table can be stored in O(min(n, m)) space.

Algorithm

  1. Allocate an (n + 1) by (m + 1) table of zeros.
  2. For each pair of prefixes, apply the recurrence above.
  3. lcs[n][m] is the length. To recover one subsequence, walk backward from that cell: a diagonal step means the characters matched and belong in the answer.

Worked example

s1 = "ace", s2 = "abcde". One LCS is "ace", length 3.

""abcde
""000000
a011111
c011222
e011223

The 1 at (a, a) comes from a match. The 2 at (c, c) adds the shared c. The 3 at the corner adds the shared e.

Complexity

Time O(n · m). Space O(n · m), or O(min(n, m)) if only the length is required.

Python

def lcs_length(s1, s2):
    n, m = len(s1), len(s2)
    prev = [0] * (m + 1)
    for i in range(1, n + 1):
        cur = [0] * (m + 1)
        for j in range(1, m + 1):
            if s1[i - 1] == s2[j - 1]:
                cur[j] = prev[j - 1] + 1
            else:
                cur[j] = max(prev[j], cur[j - 1])
        prev = cur
    return prev[m]
