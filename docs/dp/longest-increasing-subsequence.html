Dynamic Programming

Longest Increasing Subsequence

Longest subsequence that is strictly increasing. The classic DP is O(n²). A patience-sorting view is O(n log n).

Problem

Given an array of numbers, return the length of the longest subsequence that is strictly increasing. The chosen indices must increase, and so must the values.

Idea

lis[i] is the longest increasing subsequence that ends at index i. It is at least 1, the element alone. It can also extend any earlier subsequence that ends with a smaller value.

The faster method keeps tails[k]: the smallest tail of any increasing subsequence of length k + 1 seen so far. tails stays sorted. A new value either extends the longest subsequence or replaces the first tail it can improve, which leaves more room for later extensions. The length of tails is the answer. The array itself is not one subsequence.

Recurrence

lis[i] = 1, then for every j < i with arr[j] < arr[i]:

lis[i] = max(lis[i], 1 + lis[j])

The answer is max(lis). Time O(n²).

For the O(n log n) method, binary-search tails for the first entry that is greater than or equal to arr[i] and replace it. If none exists, append arr[i].

Algorithm

  1. Quadratic version: for each index, scan every earlier index and extend when the value is smaller.
  2. Logarithmic version: maintain the sorted tails list and update it with one binary search per element.
  3. Return the maximum lis[i], or the length of tails.

Worked example

Array: [10, 9, 2, 5, 3, 7, 101, 18]. One longest subsequence is [2, 3, 7, 101], length 4. [2, 5, 7, 18] is another.

lis values: [1, 1, 1, 2, 2, 3, 4, 4].

tails after each element:

valuetails afterward
10[10]
9[9]
2[2]
5[2, 5]
3[2, 3]
7[2, 3, 7]
101[2, 3, 7, 101]
18[2, 3, 7, 18]

3 replaces 5 because a subsequence of length 2 can now end smaller. 18 replaces 101 for the same reason. The length stays 4.

Complexity

DP: time O(n²), space O(n). Binary search on tails: time O(n log n), space O(n).

Python

import bisect


def lis_quadratic(arr):
    lis = [1] * len(arr)
    for i in range(len(arr)):
        for j in range(i):
            if arr[j] < arr[i]:
                lis[i] = max(lis[i], lis[j] + 1)
    return max(lis, default=0)


def lis_nlogn(arr):
    tails = []
    for x in arr:
        i = bisect.bisect_left(tails, x)
        if i == len(tails):
            tails.append(x)
        else:
            tails[i] = x
    return len(tails)
