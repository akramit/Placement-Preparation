Dynamic Programming

Longest Palindromic Subsequence

Longest subsequence that reads the same forward and backward. Subsequence, so characters in between may be skipped.

Problem

Given a string s, return the length of its longest palindromic subsequence. Every single character is a palindrome of length 1, so the answer is at least 1 for a non-empty string.

Idea

lps[i][j] is the answer for the slice s[i..j] inclusive. Short slices are solved first, then longer ones, because a longer slice depends on slices inside it.

If the two ends match, they can both sit on the outside of a palindrome built from the inside. If they do not match, one of the two ends is dropped.

The inside-without-both-ends cell is already covered by the two “drop one end” options, so it does not need its own term in the mismatch case.

Recurrence

lps[i][i] = 1

If s[i] == s[j]: lps[i][j] = 2 + lps[i + 1][j - 1], and that inside value is 0 when j = i + 1.

Otherwise: lps[i][j] = max(lps[i + 1][j], lps[i][j - 1])

Fill by substring length, from 2 up to n.

Algorithm

  1. Put 1 on every diagonal cell.
  2. For length L from 2 to n, for every start i, set j = i + L - 1 and apply the recurrence.
  3. lps[0][n - 1] is the answer.

Worked example

s = "bbbab". One longest palindromic subsequence is "bbbb", length 4.

Length 2: "bb", "bb", and "ba", "ab". Matching pairs become 2. Mismatched pairs become 1.

The full string ends with matching b characters. The inside "bba" has LPS length 2, so the full answer is 2 + 2 = 4.

Complexity

Time O(n²). Space O(n²).

Python

def longest_palindromic_subsequence(s):
    n = len(s)
    if n == 0:
        return 0
    lps = [[0] * n for _ in range(n)]
    for i in range(n):
        lps[i][i] = 1
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j]:
                inside = lps[i + 1][j - 1] if length > 2 else 0
                lps[i][j] = 2 + inside
            else:
                lps[i][j] = max(lps[i + 1][j], lps[i][j - 1])
    return lps[0][n - 1]
