Dynamic Programming

Maximum Sum Subarray

Kadane’s algorithm. Find a contiguous subarray whose sum is as large as possible.

Problem

Given an array of numbers that may contain negatives, return the largest sum of any contiguous subarray. The subarray must contain at least one element.

Idea

Any best subarray that ends at index i either is just arr[i], or is the best subarray ending at i - 1 with arr[i] stuck on the end. If the running sum so far is negative, it can only hurt the next element, so throw it away and start over at arr[i].

Recurrence

max_sum[i] = max(arr[i], arr[i] + max_sum[i - 1])

The answer is the largest max_sum[i]. Only the previous value is needed, so the table collapses to two variables.

Algorithm

  1. Set both the running sum and the best sum to arr[0].
  2. For each later element, replace the running sum with the larger of the element itself and the element plus the running sum.
  3. If that running sum beats the best sum, keep it.
  4. After one pass, the best sum is the answer.

Worked example

The best subarray is [4, -1, 2, 1], sum 6. At index 2 the running sum goes negative, so index 3 starts a new candidate.

Complexity

Time O(n). Extra space O(1).

Python

def max_subarray(arr):
    best = running = arr[0]
    for x in arr[1:]:
        running = max(x, running + x)
        best = max(best, running)
    return best
