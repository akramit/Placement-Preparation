Dynamic Programming

0-1 Knapsack

Pick items to maximize total value without exceeding a weight limit. Each item is taken once or not at all.

Problem

There are n items. Item i has weight w[i] and value v[i]. The knapsack holds at most weight W. Return the maximum total value.

Idea

dp[i][c] is the best value using only the first i items, with capacity c. Item i (stored at index i - 1) is either left out, or taken if it fits. Taking it spends w[i - 1] of capacity and adds v[i - 1], and the remaining capacity is solved using only the earlier items. That “earlier items” part is what makes the problem 0-1: the same item cannot be chosen again on this path.

Recurrence

dp[0][c] = 0 and dp[i][0] = 0

Leave it out: dp[i][c] = dp[i - 1][c]

If w[i - 1] <= c, also consider taking it:

dp[i][c] = max(dp[i][c], dp[i - 1][c - w[i - 1]] + v[i - 1])

A one-dimensional table works if capacities are scanned from W downward, so each item reads the previous item’s values rather than its own.

Algorithm

  1. Create a table with one row per item prefix and one column per capacity.
  2. For each item, for each capacity, keep the better of skipping and taking.
  3. dp[n][W] is the answer.

Worked example

Weights [2, 3, 4], values [3, 4, 5], capacity 5.

Capacity 5 with the first two items takes both: value 3 + 4 = 7. The third item weighs 4, and the leftover capacity 1 cannot hold anything better, so 7 remains the answer. Items are the first and the second.

Complexity

Time O(n · W). Space O(n · W), or O(W) with the rolling array scanned backward.

Python

def knapsack(weights, values, capacity):
    dp = [0] * (capacity + 1)
    for w, v in zip(weights, values):
        for c in range(capacity, w - 1, -1):
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[capacity]
