Dynamic Programming

Subset Sum

Decide whether some subset of the numbers adds up to a target. It is 0-1 knapsack with every value equal to its weight, asking only whether the target capacity is reachable.

Problem

Given non-negative integers and a target T, return whether any subset sums to exactly T. Each number may be used at most once.

Idea

dp[t] is true when some subset of the numbers considered so far sums to t. dp[0] is true because the empty subset sums to 0. When a new number x arrives, every sum that was already possible can also be reached with x added, as long as the new sum does not pass T.

Scan the sums from T downward. A forward scan would reuse x inside the same round, which is the unbounded (coin-change) version of the problem.

Recurrence

dp[0] = true

After considering number x, for t from T down to x:

dp[t] = dp[t] or dp[t - x]

The answer is dp[T].

Algorithm

  1. Make a boolean array of length T + 1, with only index 0 set.
  2. For each number, update achievable sums from the target downward.
  3. Read dp[T].

Worked example

Numbers [3, 4, 5], target 9. 4 + 5 works.

Complexity

Time O(n · T). Space O(T).

Python

def subset_sum(nums, target):
    dp = [False] * (target + 1)
    dp[0] = True
    for x in nums:
        for t in range(target, x - 1, -1):
            dp[t] = dp[t] or dp[t - x]
    return dp[target]
